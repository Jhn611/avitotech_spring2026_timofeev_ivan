Перед запуском:
1. Cоздайте файл .env в папке frontend.
2. Получите свой api ключ от Гигачат по ссылке https://developers.sber.ru/studio (Для получения нужно будет зарегистрироваться по номеру телефона или сбер id).
3. После, положите ключ в ранее созданный .env вот в таком виде: "VITE_GIGACHAT_AUTH_KEY=ВАШ_КЛЮЧ" !!!БЕЗ ПРОБЕЛОВ И КАВЫЧЕК!!!.
4. Скачать docker desctop (https://www.docker.com/). Запустить. Если необходимо войти/зарегистрироваться.

Запуск:
В корне проекта, без кавычек, написать в консоль - "docker compose up frontend-dev backend-dev --build"
После успешного билда фронтенд будет доступен по ссылке http://localhost:80/ 
Если по ссылке ничего нет, посмотрите в консоль, там будет написан адрес frontend-dev local и network, вам нужен local.

Принятые самостоятельные решения:
В бекенде на эндпойнте /items добавил id в передаваемые поля, для реализации полного функционала.
На странице товара добавлена кнопка назад, поскольку не была предусмотрена в дизайне, но без нее после редактирования необходимо кучу раз нажать на кнопку назад браузера, что неудобно.
На свое усмотрение были добавлены некоторые анимации не показанные в дизайне. 
Некоторые цвета и компоненты в силу нехватки времени сделаны не точно по дизайну.
Использован гигачат для облегчения работы программы на одном копьютере и в силу бесплатности решения.
